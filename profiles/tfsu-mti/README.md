# 规范原件放这里 / Put the school's spec document here

本目录用于存放**你所在学校的论文规范原件**（如 `规范原件.doc`），供 profile 追溯出处。

仓库不附带任何学校的规范文件——那是各校的文档，著作权归学校所有，不适合随开源项目分发。
`profiles/tfsu-mti.json` 里的版式常量是依据天津外国语大学 MTI 规范（2025.9.11 版）实现的，
使用前请对照你手上的规范原件自行核对。

---

This directory is where you put **your own institution's thesis format specification**
(e.g. a `.doc` from the graduate school), so the profile can cite its source.

No institutional specification is bundled with this repository — those documents belong to the
institutions that publish them. The constants in `profiles/tfsu-mti.json` were derived from the
Tianjin Foreign Studies University MTI specification (2025-09-11 edition); verify them against
your own copy before use.
